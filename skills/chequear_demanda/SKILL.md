# chequear_demanda

**Pregunta:** ¿hay ventas visibles en la búsqueda, del producto o de cualquier sustituto?

**Explica** la falta de ventas si la búsqueda entera tiene menos de 100 ventas visibles.
**Descarta** si las hay: alguien compra este tipo de producto, el problema es otro.

**Correr primero.** Si explica, los otros chequeos no hacen falta.
