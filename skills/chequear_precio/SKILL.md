# chequear_precio

**Pregunta:** ¿el producto cuesta 1,5 veces o más que la mediana de los sustitutos que venden?

**Explica** si es así: la gente compra lo que es más barato. Un importador solo tiene lugar
si puede traerlo bastante más barato que el envío courier.
**Descarta** si el precio es parecido o menor: el precio no alcanza para explicarlo.
**No se puede saber** si faltan precios.
